# SOC-Analyst-Lab-Portfolio

## 🛡️ About This Project

This repository contains hands-on SOC analyst case studies created using a home lab environment. The purpose of this project is to demonstrate real-world cybersecurity investigation workflows, including attack detection, log analysis, incident classification, and response documentation.

Each case study simulates a realistic cyber attack scenario and documents the full investigation process from detection to reporting.

This portfolio is designed to showcase practical SOC analyst skills beyond theoretical knowledge.

---

##  Lab Environment

* VirtualBox
* Kali Linux (Attacker)
* Windows 11 (Victim)
* Sysmon (Log collection)
* Event Viewer
* Wireshark / TCPDump
* MITRE ATT&CK Framework
* TryHackMe / RangeForce experience

---

##  What This Portfolio Demonstrates

* Log analysis and event correlation
* Network traffic inspection
* Attack technique identification
* MITRE ATT&CK mapping
* Incident severity classification
* Root cause analysis
* SOC style reporting
* Documentation and communication skills
